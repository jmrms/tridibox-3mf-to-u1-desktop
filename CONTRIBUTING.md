# Contributing

Contributions are welcome through GitHub pull requests.

1. Create a branch from the current default branch.
2. Make a focused change and add or update tests where appropriate.
3. Run `npm ci` and `npm test`.
4. Open a pull request explaining the change and its user-visible effect.

Changes from contributors without repository write access require review by a
maintainer before merge. Changes to build workflows, packaging, dependencies,
security boundaries or code-signing configuration require special review.
