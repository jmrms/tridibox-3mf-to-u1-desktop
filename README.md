# Tridibox 3MF to U1 Desktop

Tridibox 3MF to U1 Desktop is a portable Windows application that converts
`.3mf` projects from Bambu Studio, OrcaSlicer, PrusaSlicer, SuperSlicer and
standard 3MF files for the Snapmaker U1. All model processing is performed
locally and does not require an Internet connection.

The application includes official Snapmaker Orca machine and filament data,
four-material mapping, conversion verification and three optimized processes
for the 0.4 mm nozzle:

- Very high quality: 0.16 mm
- Standard quality: 0.20 mm
- Fast quality: 0.28 mm

See [README_ES.md](README_ES.md) for complete Spanish documentation and usage
instructions.

## Downloads

Official releases are published on this repository's **Releases** page. The
portable edition does not install system services or drivers. To uninstall it,
close the application, disable **Start with Windows** if it was enabled, and
delete the portable executable. User preferences can also be removed from the
application-data folder shown by Windows for `Tridibox 3MF to U1`.

## Build from source

Node.js 22 and npm are required:

```powershell
npm ci
npm test
npm run package:win
```

The Windows executable and source archive are written to `release/`. Official
release artifacts are generated by the public GitHub Actions workflow, not by
uploading a locally compiled executable.

## Security and privacy
