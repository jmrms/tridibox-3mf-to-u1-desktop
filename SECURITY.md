# Security policy

## Supported versions

Security fixes are provided for the latest published release of Tridibox 3MF
to U1 Desktop.

## Reporting a vulnerability

Please do not publish exploitable details in a normal issue. Use the
repository's **Security** section to open a private vulnerability report. If
private reporting is not yet enabled, open an issue containing only a request
for private contact and no sensitive technical details.

Include the affected version, Windows version, reproduction steps and the
security impact. Reports will be reviewed before public disclosure.

## Release integrity

Official Windows releases are built from the public source repository by
GitHub Actions. Once the SignPath Foundation subscription is approved, release
executables will be signed through SignPath and must match the artifact
published by the automated workflow.
