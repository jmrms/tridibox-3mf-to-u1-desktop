# Privacy policy

## Local processing

Tridibox 3MF to U1 Desktop processes 3MF files locally on the user's Windows
computer. Conversion, profile generation and verification do not require a
network connection.

## Data collection and transfer

The application does not collect telemetry, analytics, personal information or
model data. It does not upload files or transfer application information to
networked systems.

Preferences such as the watched folder, startup behavior and the local path to
Snapmaker Orca are stored only in the current user's local application-data
directory.

## External components

The application packages open-source Electron runtime components and local
Snapmaker Orca profile data. Their licenses and origins are documented in
[NOTICE](NOTICE). No third-party online service is contacted during normal use.
